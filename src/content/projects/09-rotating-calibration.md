An exploration of self-calibration techniques for a rotating camera, done for a
computer vision class project (Harvard's CS2831). In it, I implemented and
analyzed the performance of a general self-calibration algorithm proposed by a
[paper](https://link.springer.com/chapter/10.1007/3-540-57956-7_52) I had read
for the class. The class as a whole (taught by Todd Zickler) was pretty 
interesting, and I'm glad that I had the chance to take it.
