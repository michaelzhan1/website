This was a final project for a parallel computing class (Harvard's CS2050),
where we implemented a parallelized tree search chess engine using OpenMP and
MPI in C++. The actual engine is pretty bad (around 1200 Lichess rating) given
that none of us were good chess players, but it was a fun exploration into
parallel computing on a less-traditional problem.
