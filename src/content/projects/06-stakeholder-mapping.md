My master's capstone project, a collaboration with the Frontline Negotiations
organization, using multi-agent reinforcement learning to simulate a stakeholder
negotiation scenario. We built a pipeline that digests background context using
LLMs and suggests MARL-based strategies for negotiators to use to build
consensus among stakeholders, with the goal of acting as a tool to be used in
the field.
