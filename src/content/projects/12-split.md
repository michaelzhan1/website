A clone of Splitwise that I've used for vacations with my friends. It's not the
prettiest (due to my significant lack of an eye for design) and it still has
some bugs, but it works well as a very minimal expense tracker. It's a React
frontend with a Go backend, using Postgres as a database. View source on
[GitHub](https://github.com/michaelzhan1/split).
